Pronto para usar em menos de 1 minuto

Sem instaladores pesados. Uma aplicação Python pura, leve e auditável.

1
Clone ou baixe os arquivos

Obtenha o repositório diretamente do GitHub:

git clone https://github.com/jonatas07rocha/pomodoro-blur-win.git
2
Instale os requisitos

Apenas PyQt6 e Pillow para a renderização do desfoque nativo:

pip install -r requirements.txt
3
Execute silenciosamente

Dê dois cliques no arquivo iniciar.bat. O ícone aparecerá instantaneamente ao lado do relógio do Windows.

Recupere o controle da sua atenção hoje.

Código 100% aberto, sem telemetria, sem anúncios, sem contas necessárias.
